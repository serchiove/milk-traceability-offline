# Capturas ilustrativas del README

Generadas el 20/11/2026 a partir del dashboard local, con un navegador de prueba y
respuestas API simuladas. Incluyen cuatro recepciones ficticias y un total de 960 L.
Los correos reportes@example.com y jefatura@example.com son marcadores de ejemplo.

- dashboard-resumen-diario.png: resumen, correo, indicadores y detalle.
- dashboard-indicadores.png: indicadores, lotes y tanques.
- dashboard-reportes.png: filtros y los botones CSV, Excel, PDF y PowerPoint.

No se inició el backend ni PostgreSQL, no se enviaron correos y no se utilizó la
configuración SMTP privada. Estas imágenes muestran la interfaz y no sustituyen
las evidencias de integración conservadas en docs/pruebas.
